3.2-1 장기보관

비고 작성 예시: 2/3 픽업
  1. 고객의 픽업 예정일을 정확히 확인하고 예약·접수 내역과 대조합니다.
  2. 장기 보관에 해당하는 할인율을 적용하고 결제 금액을 확인합니다.
  3. 짐보관 신청 엑셀의 비고란에 픽업 예정일을 기록합니다.

3.2-2 추가 요금 발생 시

비고 작성 예시

추가 결제완료 시

2/2 추가요금 1600엔 결제완료 (캐리어 2개 추가)

추가 결제 필요 시

2/4 추가요금 00엔 결제필요 (추가 짐 미결제, 수령 시 언급)

  1. 추가 요금 발생 날짜, 금액 및 결제 상태를 확인합니다.
  2. 비고란에 날짜·금액·결제 상태를 정해진 형식대로 기록합니다.
  3. 추가 결제가 필요한 건은 인수인계 시 공유하고, 결제 완료 후 기록을 갱신합니다.

3.2-3 마감 시 미수령 짐보관 관리

  1. 마감 전 미수령 짐이 있는지 확인합니다.
  2. 고객에게 연락할 수 있는 경우, 마감 전에 미리 연락하여 수령 여부와 예정 시간을 확인합니다.
  3. 21시까지 수령하지 않은 짐은 추후 고객의 연락이나 긴급출동 요청이 발생할 수 있으므로, Google Chat에 미수령 현황을 공유합니다.
  4. 공유 시 고객명·보관 번호·짐 수량·연락 여부·수령 예정일 등 업무에 필요한 사항을 기재하고 다음 근무자에게 인계합니다.

긴급출동 관련 자세한 사항은 5.2 긴급출동 대응 자세히 보기 →를 참고하세요.

3.2-4 접수 시 파손된 짐

  1. 캐리어 외관에 눈에 띄는 파손이나 이상이 있으면 메모란에 기록합니다. (예: 캐리어 손잡이 파손, 캐리어 바퀴 없음 등)
  2. 고객에게 해당 부위를 보여주며 “이 부분 괜찮으세요?”와 같이 간단하게 상태를 확인합니다.
  3. 접수 당시 촬영한 짐보관 신청 사진도 추후 상태 확인에 활용합니다.

현장 불만 응대 예시

불편을 드려 죄송합니다. 우선 센서 부분의 스크래치나 손상 여부를 확인하겠습니다. 외관상 문제가 없다면 저희 직원이 별도로 센서 작동 상태를 확인하고, 이상이 확인될 경우 따로 연락드려 환불 조치를 진행하겠습니다.

  • 해외 발송 대행수수료 10,000엔을 한국 반납에 자동 추가하지 않음

6.3-6 한국 수령 · 검수

  1. 택배 배송 완료 일시 기록
  2. 국내 담당자 실제 수령 일시 기록
  3. 개봉, 외관, 구성품, 상품별 작동 상태 검수
  4. 출고 전 기록과 수령 사진 비교하여 확인 가능한 손상만 기록
  5. 영서 담당자가 파손 여부 확인 후 고객 반납 처리

6.3-7 보관 및 일본 센터 재입고

  1. 영서 담당자가 한국에서 상품 보관
  2. 추후 일본 방문 시 반입 절차 확인 후 운반
  3. 일본 센터에서 실물·수량·구성품·상태 대조
  4. 일본 입고 일시 기록 후 정상 상품만 대여 가능 재고에 재반영
고객 반납 완료 ≠ 일본 센터 재입고 완료. 일본 실물 입고 이전에는 대여 가능 재고에 추가하지 않습니다.

한국으로 가져가신 렌탈 상품은 지정된 국내 반납지로 택배 발송해 주시면 됩니다. 국내 택배비는 고객님 부담이며, 기본 처리비와 실제 연체료를 비교해 더 높은 금액 하나만 청구합니다. 발송 전 상품 및 구성품·포장 사진을 촬영해 주시고 송장번호를 알려주세요. 상품 수령과 검수 후 최종 반납 처리해 드리겠습니다.

6.4-1 해외 발송 처리 절차

  1. 접수

    주문·보관 기록을 확인해 물품과 수량, 수취 국가, 수취인 및 배송방법을 확인합니다.

  2. 예약·견적

    고객이 일본 현지 배송업체에 픽업을 예약합니다. 배송사 규격, 금지품, 통관 및 수취 가능 여부를 확인하고, 국제배송비·대행수수료·추가 보관료·포장비를 구분해 총액과 통화를 안내합니다.

  3. 준비·CCTV

    날짜·수량·무게·크기·기존 손상·포장 상태를 기록하고 사진을 남깁니다. 짐 개봉·포장·발송·기사 인계 전 과정을 CCTV 영상에 담을 수 있는 구도에서 진행합니다.

  4. 결제

    실제 결제 완료 증빙과 견적 총액을 대조한 뒤 발송합니다. 결제 요청 또는 견적서 발행만으로 결제 완료 처리하지 않습니다.

  5. 인계·사후 확인

    예약 내용과 물품을 대조하고 배송사·송장번호·인계 일시를 기록합니다. 고객에게 송장과 접수 결과를 안내하고 배송 조회로 완료 여부를 별도 확인합니다.

  6. 기존 건 처리

    이미 결제한 건에는 새로운 수수료를 추가 청구하지 않습니다. 진행 중이거나 이전 금액을 안내한 건은 기존 안내·결제 내역을 확인해 별도 판단합니다.

6.5 짐보관 사고·파손 발생 시 대응

6.5-1 접수 시 파손 확인

  1. 캐리어 외관에 눈에 띄는 파손이나 이상이 있으면 메모란에 기록합니다. (예: 캐리어 손잡이 파손)
  2. 고객에게 해당 부위를 보여주며 “이 부분 괜찮으세요?”와 같이 간단하게 상태를 확인합니다.
  3. 접수 당시 촬영한 짐보관 신청 사진도 추후 상태 확인에 활용합니다.

6.5-2 사고 발생 시 처리 절차

  1. 현장 기록

    사고 발생 즉시 사진을 촬영하고 발생 일시, 장소, 상황 및 상품 상태를 기록합니다.

  2. 고객 응대

    불편에 대해 사과하고 현장에서 확인된 사실을 설명합니다. 확인되지 않은 책임이나 보상은 약속하지 않습니다.

  3. 내부 보고

    내부 담당자에게 즉시 보고하고 후속 대응을 협의합니다.

  4. 사고 보고서·승인

    사고·파손 발생 보고서를 작성하고 대표님 승인 후 대응 절차와 결과를 기록합니다.

6.5-3 보관 후 파손 클레임 대응

접수 당시 이상이 없었으나 고객이 보관 후 파손을 주장하는 경우, 우선 “확인 후 안내드리겠습니다.”라고 응대합니다. 평소 보관 과정과 CCTV 확인 예정임을 설명하되, 조사 전 책임 여부를 단정하지 않습니다.

  1. 접수 사진과 비고란, 인수인계 기록을 대조합니다.
  2. 매니저 또는 대표님에게 CCTV 확인을 요청합니다.
  3. 승인된 범위에서 영상 확인 결과를 고객에게 설명하고, 처리 및 종결 내용을 기록합니다.

6.5-4 파손 책임 범위 문의 시 안내

고객 응대 예시

저희는 고객님의 짐을 소중히 보관하고 있습니다. 다만 짐을 옮기는 과정에서 생길 수 있는 일반적인 스크래치나 바퀴 마모 등은 책임지기 어려운 점 양해 부탁드립니다.

반면 저희의 명백한 과실로 보관 중 크게 파손된 경우에는 확인 후 책임지고 조치하겠습니다. 걱정되시면 맡기시기 전 가방 상태를 사진으로 남겨두셔도 좋습니다. 짐보관 신청 시 촬영한 사진으로도 상태를 확인할 수 있습니다.
